# 🍽️ MunchMap

A restaurant recommendation web application that helps you discover great places to eat based on your preferences.

## 📋 Overview

MunchMap is a full-stack web application that combines a React frontend with a Django backend to deliver personalized restaurant recommendations. Browse, search, and save your favorite dining spots all in one place.

## 🚀 Getting Started

### Frontend Setup

```bash
cd munchmap/frontend
npm i
npm run dev
```

### Backend Setup

```bash
cd munchmap/backend
venv\Scripts\activate
python manage.py runserver
```

## 🔧 Features

- Restaurant discovery based on location and cuisine
- User reviews and ratings
- Personalized recommendations
- Save favorite restaurants
- Interactive maps
